# Habit Tracker

Приложение для отслеживания привычек. Проект написан на React, TypeScript и Vite.

## Что умеет приложение

- добавлять привычки с названием, цветом и иконкой;
- отмечать выполнение привычки за текущий день;
- удалять привычки;
- показывать прогресс за день и максимальную серию выполнений;
- сохранять данные в `localStorage` браузера.

## Выбор технологий

Проект сделан на React, TypeScript и Vite. React выбран для построения интерфейса из компонентов и удобной работы с состоянием, TypeScript помогает заранее находить ошибки в данных привычек, а Vite используется как быстрый и простой инструмент сборки для небольшого SPA-проекта.

React Router не используется, потому что в приложении нет полноценной маршрутизации между отдельными URL-страницами. Переключение между привычками и статистикой реализовано локальным состоянием в `App.tsx`, этого достаточно для текущего масштаба. По сравнению с React Router и TanStack Router такой подход проще и не добавляет зависимость, которая нужна только при росте количества страниц и необходимости ссылок на конкретные разделы.

Zustand и Redux Toolkit не используются, потому что состояние приложения небольшое: список привычек хранится в `App.tsx`, а операции добавления, удаления и отметки вынесены в сервисы. Redux Toolkit был бы избыточен из-за большого количества шаблонного кода для такого проекта, а Zustand полезнее, когда одно и то же состояние нужно во многих независимых частях интерфейса. Сейчас передача данных через props остается понятной и достаточной.

UI-библиотеки не используются, потому что интерфейс проекта небольшой и полностью описан собственными CSS-стилями. Material UI или Ant Design дали бы готовые компоненты, но увеличили бы размер зависимостей и сделали внешний вид более шаблонным. Собственная стилизация лучше подходит для учебного проекта, где важно показать понимание верстки, адаптации и состояний элементов.

## Требования

Перед запуском установите:

- Node.js;
- npm.

Проверить установку можно командами:

```bash
node -v
npm -v
```

## Установка

Перейдите в папку проекта:

```bash
cd HabitTracker
```

Установите зависимости:

```bash
npm install
```

Если папка `node_modules` уже есть, этот шаг можно пропустить, но после скачивания проекта на новом компьютере зависимости нужно установить заново.

## Запуск в режиме разработки

Запустите локальный сервер:

```bash
npm run dev
```

После запуска Vite покажет адрес приложения в терминале. Обычно это:

```text
http://localhost:5173/
```

Откройте этот адрес в браузере.


## Структура проекта

```text
src/
  components/   Компоненты интерфейса
  models/       TypeScript-типы
  services/     Логика работы с привычками, статистикой и localStorage
  App.tsx       Основной компонент приложения
  main.tsx      Точка входа
public/         Статические файлы
dist/           Собранная версия приложения
```

## Данные

Приложение хранит привычки в `localStorage` браузера. Серверная база данных не используется.

Если открыть приложение в другом браузере или очистить данные сайта, сохраненные привычки будут недоступны.
