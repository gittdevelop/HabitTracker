# Habit Tracker

Приложение для отслеживания привычек. Проект написан на React, TypeScript и Vite.

## Что умеет приложение

- добавлять привычки с названием, цветом и иконкой;
- отмечать выполнение привычки за текущий день;
- удалять привычки;
- показывать прогресс за день и максимальную серию выполнений;
- сохранять данные в `localStorage` браузера.

## Требования

Перед запуском установите:

- Node.js;
- npm.

Проверить установку можно командами:

```bash
node -v
npm -v
```

## Установка

Перейдите в папку проекта:

```bash
cd HabitTracker
```

Установите зависимости:

```bash
npm install
```

Если папка `node_modules` уже есть, этот шаг можно пропустить, но после скачивания проекта на новом компьютере зависимости нужно установить заново.

## Запуск в режиме разработки

Запустите локальный сервер:

```bash
npm run dev
```

После запуска Vite покажет адрес приложения в терминале. Обычно это:

```text
http://localhost:5173/
```

Откройте этот адрес в браузере.


## Структура проекта

```text
src/
  components/   Компоненты интерфейса
  models/       TypeScript-типы
  services/     Логика работы с привычками, статистикой и localStorage
  App.tsx       Основной компонент приложения
  main.tsx      Точка входа
public/         Статические файлы
dist/           Собранная версия приложения
```

## Данные

Приложение хранит привычки в `localStorage` браузера. Серверная база данных не используется.

Если открыть приложение в другом браузере или очистить данные сайта, сохраненные привычки будут недоступны.
